# 07 — Capability Roadmap

| Increment | Outcome | Key capabilities | Exit evidence |
|---|---|---|---|
| C0 — Foundation | Governed MESA ecosystem | Roles, identifiers, repositories, contracts, BDD, decision rights | Foundation review |
| C1 — Mission baseline | Agreed outcome and thread | Context, actors, measures, constraints, operational thread | Mission-fit decision |
| C2 — Architecture baseline | Allocated logical architecture | Requirements, functions, systems, interfaces, traceability | Baseline approval |
| C3 — Cyber integration | Threat-informed assurance | Threats, controls, evidence, authorization dependencies | Assurance architecture review |
| C4 — Cloud integration | Executable transformation | Workload mapping, target cloud, waves, cutover/rollback | Migration readiness review |
| C5 — End-to-end verification | Mission thread proven | Contract, system, security, data, recovery, decision tests | Operational acceptance |
| C6 — Sustainment | Continuously governed ecosystem | Monitoring, change impact, roadmap, debt, cost, recovery | Sustainment maturity review |

## Roadmap priority

Prioritize by mission consequence/opportunity, dependency enablement, risk reduction, decision evidence, reuse, feasibility, and learning. Feature count is secondary to reducing uncertainty in the highest-consequence operational thread.
