# ADR-001 — Preserve Constituent-System Domain Authority

- **Status:** Accepted
- **Decision:** Each constituent system remains authoritative for its domain and shares governed projections through APIs/events.
- **Drivers:** Autonomy, ownership, independent lifecycle, auditability, reduced coupling.
- **Rejected alternative:** One shared ecosystem database.
- **Consequences:** Stronger boundaries and provenance; requires canonical identifiers, reconciliation, and contract governance.
