# Cloud Readiness Gates

## Platform foundation gate

- [ ] Organization, OUs, accounts, ownership, and closure workflow approved
- [ ] Federation, privilege elevation, emergency access, and workload identity tested
- [ ] Network routing, DNS, ingress, egress, inspection, and hybrid paths tested
- [ ] Keys, secrets, certificates, audit, logs, findings, and incident routing active
- [ ] Backup, restore, observability, IaC, drift, budgets, and quotas operating
- [ ] Platform SLOs, runbooks, support, recovery, and dependency limitations published

## Workload design gate

- [ ] Mission outcome, users, criticality, RTO/RPO, performance, and data authority defined
- [ ] 7R disposition and target pattern approved
- [ ] Dependencies and interfaces validated
- [ ] Identity, network, security, data, observability, backup, and cost designs approved
- [ ] ADRs, IaC, migration, test, cutover, rollback, and decommission plans reviewed

## Cutover gate

- [ ] Rehearsal passed in representative conditions
- [ ] Functional, interface, security, data, performance, resilience, and operations evidence current
- [ ] Final synchronization and reconciliation procedure proven
- [ ] Rollback trigger, deadline, reverse data handling, and authority confirmed
- [ ] Staffing, communications, partners, users, service desk, and leadership prepared
- [ ] Exceptions and residual risks approved and time-bounded

## Stabilization and legacy-exit gate

- [ ] Mission thread, SLO, incident, user, data, security, and cost thresholds met
- [ ] Recovery remains functional and operations accepts ownership
- [ ] Rollback window formally closed
- [ ] Legacy consumers, data, interfaces, identities, routes, jobs, records, and licenses resolved
- [ ] Infrastructure and contracts terminated or exception approved
- [ ] Inventory, diagrams, financial baseline, evidence, and lessons learned updated
