# Capability Roadmap Backlog

| Increment | Epics | Proof point | Gate |
|---|---|---|---|
| C0 — Mobilize | EP-01 foundations | Complete inventory and disposition for pilot group | Mission fit |
| C1 — Foundation | EP-02, EP-03, EP-04, EP-07 | Governed account with identity, network, security, logs, backup, budget | Foundation readiness |
| C2 — Pilot | EP-05, EP-06 | Two synthetic workloads migrated, rehearsed, accepted, and retired | Pilot acceptance |
| C3 — Scale | All | Repeatable wave using approved patterns and evidence | Factory scale |
| C4 — Critical/data | EP-05, EP-06, EP-07 | Tier 1/2 data, recovery, and cutover evidence | Critical readiness |
| C5 — Modernize | EP-04, EP-05, EP-07 | Managed/event-driven pattern shows measurable value | Modernization value |
| C6 — Exit/optimize | EP-08 | Legacy cost closure and sustained cloud operating model | Transformation closure |

## Prioritization

Rank work by mission consequence/opportunity, dependency enablement, risk reduction, decision evidence, platform reuse, feasibility, and learning. Application count and migration speed are secondary to safe mission outcomes and actual legacy exit.
