# Security Policy

This repository is documentation and synthetic sample data, not deployed software.

Do not submit real vulnerabilities, credentials, hostnames, IP addresses, diagrams, control implementations, evidence, mission data, customer data, classified information, CUI, export-controlled data, or proprietary content through issues or pull requests.

For a documentation concern, open a GitHub issue containing only public-safe information. For a potentially sensitive concern, do not post it publicly; contact the repository owner through an approved private channel.
